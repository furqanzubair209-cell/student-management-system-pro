# 🎓 Student Management System (Vanilla JS)

A fully functional Student Management System built using:

- HTML5  
- CSS3  
- Vanilla JavaScript  
- Chart.js  
- LocalStorage  

This project includes both **Admin Panel** and **Student Portal** with interactive dashboards, data tables, analytics charts, and full CRUD functionality.

---

### 🧑‍🎓 Student Login
